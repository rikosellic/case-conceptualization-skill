# 临床工作流程

本指南用于根据心理咨询或心理治疗材料生成专业个案概念化分析，并为治疗师提供后续干预指导。固定身份与强制入口规则见根目录 `AGENTS.md`。

## 知识库地图

知识边界及禁止使用的来源以根目录 `AGENTS.md` 为唯一权威。本节只说明 `./knowledge/` 的模块分布：

| 模块 | 路径 | 内容 |
|------|------|------|
| 个案概念化 | `./knowledge/个案概念化/` | CBT 个案概念化（Persons, 2008）、心理动力学个案概念化（Cabaniss, 2013） |
| 综合理论 | `./knowledge/Counseling and Psychotherapy Theories in Context and Practice/` | 13 种咨询与心理治疗理论，各章均含个案概念化模板与干预技术 |
| 干预 | `./knowledge/干预/` | 14 本干预手册/指南（DBT、CBT、IPT、SFBT《尊重与希望 焦点解决短期治疗》、正念、团体、Clinical Interviewing 临床面谈/自杀评估/诊断与治疗计划、家庭治疗技术、CBT 实践指南等） |
| 诊断 | `./knowledge/诊断/` | DSM-5 中文版、ICD-11 临床描述与诊断指南 |
| 模板 | `../templates/` | 5 个模板：4 个流派报告模板 + 1 个干预指导模板（`.md` markdown解析版 + `.docx` 原件） |

## 三级知识读取体系

所有知识按深度分为三级，agent 必须严格遵循读取纪律：

| 级别 | 定义 | 内容 | 何时使用 |
|------|------|------|----------|
| **L1 索引级** | 导航与框架 | `*_index.md` 文件，含章节导览、核心概念速览、Agent 使用建议 | 每次任务的起点——确定需要读哪些章节文件 |
| **L2 章节级** | 结构化知识 | 章节合并 `.md` 文件（如 `_01_03_总论与三步法.md`），含理论框架、操作方法和临床要点 | **默认分析深度**——绝大多数任务在此完成 |
| **L3 原文级** | 完整原文 | `book/` 目录下的完整书籍 `.md` 文件，含逐页原文 | **仅在明确触发条件下进入** |

### L3 原文触发条件

满足以下任一条件时，方可从 L2 进入 L3 读取 `book/` 原文：

1. 需要精确的技术步骤、练习引导语或表格字段
2. 需要核对诊断标准的精确措辞（边界鉴别场景）
3. 需要特定疗法的会话脚本或示范对话
4. L2 章节文件中的描述不足以解决用户的具体技术问题
5. 用户明确追问"原文怎么说的""具体步骤是什么""书里原话是什么"

### 不应进入 L3 的场景

以下场景必须停在 L2，不得读取 `book/` 原文：

1. 常规个案概念化分析
2. 理论框架解释或流派概述
3. 一般性干预方向建议
4. 症状模式识别或维持机制推断

**诊断特殊规则**：常规症状群识别和鉴别方向使用 L2 章节文件（DSM-5/ICD-11 章节文件已含诊断标准概要）；仅在边界案例、诊断争议或用户追问精确诊断标准时进入 L3。

## 材料处理

### 用户传入 PDF 材料时

> **⚠️ 必须使用本项目自带的 `../scripts/pdf-analyzer` 提取 PDF 内容。禁止使用 agent 内置的 PDF 读取能力或其他第三方 PDF skill。**

#### 前置检查

在执行提取前，先确认 `pdf-analyzer` 环境已就绪：

| 检查项 | 命令（Windows） | 命令（Linux/macOS） |
|--------|----------------|---------------------|
| `uv` 是否可用 | `Get-Command uv` | `which uv` |
| 依赖是否已同步 | `Test-Path .venv` | `test -d .venv` |
| `pdftoppm` 是否可用（OCR 需要） | `Get-Command pdftoppm` | `which pdftoppm` |

决策流程：

```
需要提取 PDF
  → 切换到 ../scripts/pdf-analyzer 目录
  → uv 是否可用？
     ├─ 否 → 运行安装脚本（见下方）
     └─ 是 → .venv 是否存在？
              ├─ 否 → 执行 uv sync
              └─ 是 → 是否需要 OCR？
                       ├─ 是 → pdftoppm 可用？
                       │        ├─ 否 → 运行安装脚本
                       │        └─ 是 → 执行提取命令
                       └─ 否 → 执行提取命令
```

环境未就绪时，运行安装脚本：

- **Windows**：`..\scripts\pdf-analyzer\scripts\install.ps1`
- **Linux/macOS**：`../scripts/pdf-analyzer/scripts/install.sh`

安装脚本会自动处理。

#### 提取内容

确认环境就绪后，在工作目录 `../scripts/pdf-analyzer/` 下执行：

- 可复制文字 PDF：`uv run pdf-extract "file.pdf" -o "../scripts/pdf-analyzer/tmp/extracted.md"`
- 扫描版 PDF：`uv run pdf-ocr "scanned-file.pdf" -o "../scripts/pdf-analyzer/tmp/extracted.md"`

> ⚠️ 要求优先使用绝对路径执行 `pdf-analyzer`，把原始 PDF 和输出 Markdown 都写成绝对路径。
> 例如：`uv run pdf-ocr "D:\Projects\AI\psychotherapist\references\books\scanned\foo.pdf" -o "D:\Projects\AI\psychotherapist\scripts\pdf-analyzer\tmp\extracted.md"`
>
> 默认规则：提取后的 Markdown 先输出到 `../scripts/pdf-analyzer/tmp/` 目录中；只有在后续确实需要长期保存或归档时，才复制到更稳定的位置。任务完成后，如临时文件不再需要，应清理 `tmp/` 中的提取产物。

#### 后续处理

读取提取后的 Markdown 文件，进入分析流程。

### 用户传入文本/Markdown/对话记录时

直接读取材料内容，进入分析流程。

## 工作流程

> **输出形态（结构、节奏、篇幅、是否使用模板）由当前启用的 SOUL 文件决定。** 本工作流程只规定分析时需要思考的维度（思考结构），不规定输出的章节序列（输出结构）。当 SOUL 文件中关于自由分析/正式报告的输出形态描述与本工作流程的 §4、§5 冲突时，以 SOUL 为准。

### 0. 判断任务模式

在进入知识读取和分析之前，先判断用户请求属于哪种模式：

| 模式 | 典型触发语 | 输出形态 |
|------|-----------|---------|
| **自由分析** | "分析一下""谈谈看法""你怎么看""讨论""梳理思路""自由分析"，或用户未指定输出格式 | 对话式、非结构化；聚焦 3–5 个关键临床判断；保留讨论感和不确定性 |
| **正式报告** | 用户请求中出现「报告」一词（如"写个案报告""督导报告""生成报告""概念化报告"），或明确要求"按模板输出""做个完整的个案概念化" | 可使用模板结构、编号章节；完整覆盖各维度 |

**默认规则：用户请求中出现「报告」一词时，一律判定为正式报告模式。** 未出现「报告」「模板」「正式」且未指定输出格式时，默认为自由分析模式。模式判断结果影响后续 §4 和 §5 的输出方式。

**自由分析模式下的文件输出**：当用户在自由分析中要求"保存到文件""输出为文档""写个文件"等，若对话框中已存在完整的分析内容，直接将该内容复制写入文件，不得重新生成一份内容不同或格式不同的新文件。仅当对话框中尚无分析内容、或用户明确要求不同的输出格式（如"整理成正式报告"）时，才重新生成。

### 1. 明确任务与材料状态

先判断：

- 用户提供的是初访记录、咨询记录、治疗逐字稿、评估摘要、督导材料，还是报告草稿。
- 用户是否指定理论取向或诊断系统。
- 材料中是否出现风险线索：自杀、自伤、伤人、虐待、精神病性症状、躁狂、严重物质使用、进食障碍风险、解离或保护性议题。

### 2. 提取临床相关信息

将原始材料整理为：

- 基本信息与材料来源
- 主诉与求助动机
- 当前症状、困扰和功能受损
- 诱发事件与近期压力源
- 问题的发展过程
- 重要成长史、家庭史、依恋经验和关系经验
- 既往治疗史、诊断史和用药史
- 治疗师已经使用过的干预技术、治疗意图和来访者反应
- 咨询过程中的互动模式、阻抗、联盟变化和情绪反应
- 资源、优势与保护因素
- 风险线索与伦理注意事项

按 `AGENTS.md` 的事实忠实性边界处理材料。操作上，凡不能由材料直接支持的动机、诊断、创伤机制、人格模式或家庭动力，都只能写为临床推论、待验证假设或信息缺口。

#### 来访者自述的选取与归纳

> 报告中的"来访者自述"是概念化的证据基础。选取和归纳质量直接影响概念化的可信度。

1. **选典型，不堆砌**。从材料中选取最能代表来访者核心困难、典型模式或关键转折的自述，而非随机或等距摘录。每条被选中的自述应能服务于至少一个概念化环节（主诉定性、维持机制说明、资源识别等）。
2. **多归纳，少搬运**。对来访者的散在表述做归纳整合，而非逐句搬运。例如：来访者在三次咨询中分别提到"同事不理我""朋友约饭不叫我""家人也不理解我"→ 归纳为"来访者在多个人际情境中体验到被排斥和孤立（材料依据：第1/3/5次咨询记录）"，而不是列出三句孤立原话。
3. **归纳时保留原汁原味**。归纳后的表述仍应使用来访者自己的语言习惯和情感色调。若来访者用"烦死了"描述情绪，归纳时保留"烦躁"而非替换为学术化的"焦虑体验"。学术术语留给分析段落。
4. **每段归纳附锚定**。归纳段落后附材料出处（如"（材料依据：第2次咨询，来访者自述）"），使读者可回溯原文验证。
5. **数量控制**。一份完整的个案概念化报告中，引用/归纳来访者自述通常 5–10 处为宜（视材料丰富度调节）。少于 3 处则概念化缺乏证据基础；多于 15 处则可能堆砌而缺乏分析深度。
6. **自述与分析的配比**。报告整体上自述（事实层）与分析（推论层）的比例约为 3:7 到 4:6。避免两种极端：全是自述没有分析（变成材料摘抄），或全是分析没有自述（变成脱离材料的理论推演）。

### 3. 确定分析路径

**必须先读** `./guides/个案概念化任务读取指南.md`，按以下决策链确定分析路径：

```
材料特征 → 查指南中的理论取向匹配规则
  → 确定主要理论取向
    → 读取对应书籍的 *_index.md（L1）
      → 按 index 中的「Agent 使用建议」决定读哪些章节文件（L2）
        → 以 L2 知识完成分析
          → [仅在 L3 触发条件下] 进入 book/ 原文
```

**无明确取向时**：先读 `./knowledge/Counseling and Psychotherapy Theories in Context and Practice/Counseling and Psychotherapy Theories in Context and Practice_index.md`，扫描各理论核心特征，按材料呈现的主要症状/模式/关系特征自动匹配最相关的 1–2 个理论。

**干预技术识别时**：根据个案概念化中识别的维持机制，查指南中的干预匹配表，确定需要读取的干预书籍，按同样顺序（index → 章节文件）获取知识。

**临床面谈/风险评估时**：涉及初始面谈结构、摄入报告、精神状态检查（MSE）、自杀/自伤风险评估、安全计划、诊断面谈、治疗计划、挑战性来访者、青少年/伴侣/家庭面谈或多元文化面谈时，优先读取 `./knowledge/干预/Clinical_Interviewing_F_o_u_r_t_h_E_d_i/Clinical_Interviewing_F_o_u_r_t_h_E_d_i_index.md`，再按 index 建议读取对应章节文件。

**涉及诊断时**：按症状群查指南中的诊断模块，确定读取 DSM-5 或 ICD-11，按 index → 章节文件顺序获取诊断标准概要。诊断仅作为假设和鉴别方向，不做确定诊断。

### 4. 形成概念化

以 L2 章节文件中的理论知识为基础，将提取的临床信息组织为概念化假设。

**思考维度（内部使用，不直接输出）**——以下维度仅供 agent 在内部分析时考量，不得作为输出结构的组织逻辑或段落标题：

- 来访者为什么在此时求助
- 表层问题、功能损害和主要困扰是什么
- 哪些易感因素、发展经验或关系经验可能塑造了当前问题
- 哪些近期因素诱发或激活了当前困难
- 哪些认知、情绪、行为、关系、身体反应、系统和环境机制维持了问题
- 哪些资源、优势和保护因素可以被治疗利用
- 哪些假设仍不确定，需要进一步评估

**输出区分（按 §0 判定的模式）**：

- **正式报告模式**：以上各维度在输出中尽量完整覆盖；可使用模板结构或编号章节。必要时可使用最低限度框架组织输出：表层问题 → 形成因素 → 诱发因素 → 维持机制 → 核心假设 → 资源与保护因素 → 治疗含义。
- **自由分析模式**：禁止将上述维度名称（维持机制、形成因素、核心假设、诱发因素、治疗含义、资源与保护因素等）用作输出标题或段落组织标签——这些是内部思考辅助，不是面向治疗师的输出结构。从以上维度中选取 2–4 个对理解当前个案最具区分度的关键判断深入展开；不按固定顺序排列；不按框架维度逐一展开（不要写成"形成因素→诱发因素→维持机制→治疗含义"的流水线）；让每个判断自然引出下一个；以临床观察或判断命名段落（如"不是抑郁，是羞耻"），而非以理论分类命名（如"维持机制分析"）；主动标注不确定性（如"这部分材料还看不清，暂时保留两种理解"）；其余维度仅在自然相关时提及，不必逐项罗列。输出的目标是推进讨论，而非完成全套概念化。

### 5. 生成干预指导

干预指导必须基于已完成的个案概念化，而不是直接从孤立症状跳到技术建议。

使用指南中的干预匹配表，从相关干预书籍的 L2 章节文件中获取知识。

**思考维度（两种模式共用）**——分析时，以下维度都需要在内部考量：

- 短期工作重点：安全、联盟、评估、稳定化、症状缓解和治疗框架
- 中期工作重点：核心维持机制、情绪/认知/关系模式、技能训练或经验加工
- 长期工作重点：人格或关系模式改变、复发预防、意义整合和生活结构调整
- 治疗师需要注意的难点：联盟风险、回避/阻抗、情绪过载、边界议题、反移情和风险升级
- 可使用的技术方向：只纳入被所选流派和个案概念化支持的技术
- 观察指标：如何判断干预是否有效，以及何时需要调整治疗策略

每条干预建议都应说明：
- 它针对概念化中的哪个维持机制
- 它为什么适合来访者当前表现
- 治疗师需要观察什么

**输出区分（按 §0 判定的模式）**：

- **正式报告模式**：以上各维度在输出中尽量完整覆盖；可按短期/中期/长期分段展开；每条技术建议说明针对的维持机制、适用理由和观察指标。
- **自由分析模式**：从概念化结果中选 1–3 个最有杠杆效应的干预方向讨论，而非罗列完整的阶段化路线图。优先讨论"下一步最值得做什么、为什么、需要注意什么"，而非逐期规划。可以邀请治疗师回应（如"这个方向你觉得在你们的联盟里推进得动吗？"）。技术建议保持简洁，重点放在临床判断而非操作清单。

## 输出规则

### 三种输出形态

收到用户请求时，只在以下三种输出形态中选择一种：

| 条件 | 输出形态 | 行为 |
|------|---------|------|
| 用户询问问题、请求分析/看法/思路、讨论治疗难点或下一步，且未明确要求可归档的报告或系统干预方案 | **自由分析（默认）** | 不调用报告模板；完全按照当前 `SOUL` 的语气，以可以继续接话的对话和讨论方式回应 |
| 用户明确要求“正式报告”“完整/简要个案概念化”“督导汇报”“按某模板生成”或其他可直接归档、提交、汇报的文稿 | **结构化报告** | 按主要流派自动选择报告模板；用户要求的简要程度、督导重点或理论取向作为报告侧重点处理 |
| 用户明确要求一份系统、完整、可执行的后续干预指导或干预方案 | **干预指导** | 使用干预指导模板；根据用户是否已提供概念化，自动决定是否附必要的简要概念化摘要 |

**判断原则**：材料丰富或足以支持深入分析，不构成自动进入结构化输出的理由。用户没有明确要求报告式产物或系统干预方案时，一律默认自由分析。无法判断时也使用自由分析，不在结尾主动推销其他输出形态。

#### 写作前强制分流

起草正文前依次判断：

1. 用户是否明确要可归档、提交或汇报的报告？是 → **结构化报告**。
2. 用户是否明确要系统、完整的干预方案？是 → **干预指导**。
3. 其余情况 → **自由分析**。

“帮我分析”“你怎么看”“给点思路”“下一步怎么做”“深入分析一下”都属于自由分析，不等于要求报告或完整干预方案。不得因为材料长、可分析内容多或读取了多个知识文件而擅自升级输出形态。

### 结构化报告

#### 模板选择

从 `../templates/` 中按以下规则选择模板：

| 用户指定/材料特征 | 使用模板 |
|---|---|
| 明确要求 CBT 取向，或材料核心为自动思维、行为循环、症状监测 | `../templates/认知行为治疗记录.md` |
| 明确要求心理动力学或精神分析取向，或材料核心为关系模式、防御、移情、发展史 | `../templates/动力学个案报告提纲.md` |
| 明确要求家庭/系统取向，或材料核心为家庭互动、代际模式、三角化 | `../templates/家庭案例督导汇报提纲.md`（⚠️ 家庭治疗记录分析时，不能仅参考知识库中家庭治疗理论的内容，还需兼顾来访者个体的分析——包括个体症状、发展史、人格模式、个体维持机制等，防止只见系统不见人） |
| 未指定流派、多机制并存、或要求完整专业报告 | `../templates/中德班_案例报告格式.md`（默认） |

结构化报告可在多个报告模板之间取长补短：当个案涉及多个层面时（如个体症状+家庭系统），以主要报告模板为骨架，补充其他报告模板的相关字段；不叠加干预指导模板。

#### 模板使用方式

- 模板 `.md` 文件为markdown解析版，与docx原件内容一致。
- 以模板的结构（标题层级、字段顺序）组织输出。
- 概念化内容来自 `./knowledge/` 知识库的 L2 分析结果，填入模板结构。
- “简要”“督导重点”“指定流派”等要求只调整报告长度、关注重点或模板选择，不形成新的输出形态。

### 干预指导

- 使用 `../templates/干预指导模板.md`，但只输出干预指导所需内容，不与结构化报告叠加。
- 用户已经提供可用的概念化或报告时，不重复生成概念化摘要。
- 用户尚未提供概念化时，Agent 内部完成必要概念化，并在干预建议前附一段足以说明问题锚点和维持机制的简要摘要。
- “是否附摘要”只由材料状态自动决定，不形成两个独立的干预指导形态。

### 避免冗余

同一输出中遵守以下规则，防止内容重复：

#### 跨模块去重

1. **概念化已详述的内容，干预部分仅引用不重述**。干预建议中的"回链概念化"为一句话指针（如"针对概念化中的情绪失调维持循环"），不对维持机制做完整再描述。
2. **同一临床信息不在同一输出中出现两次**。若来访者的核心维持机制已在概念化部分完整描述，干预部分不重复展开该机制的分析推理过程。
3. **多条干预建议指向同一维持机制时，合并机制描述，分别展开技术建议**。不在每条建议中重复说明同一机制。
4. **报告模板组合时，划分内容边界**。结构化报告若参考多个报告模板，应明确主模板和补充字段，同一临床信息只保留一处；干预指导模板不参与报告模板组合。

#### 概念化内部去重

5. **每个临床模式只展开一次**。同一心理模式（如"回避亲密关系"）在概念化中只做一次完整分析，后续引用时仅用一句话回指。例如：若"回避亲密关系"已在"维持机制"部分详细描述了其起源、表现和后果，则"核心假设"和"治疗含义"部分仅回指而不重述。
6. **"形成因素 → 维持机制 → 治疗含义"链条中去重**。来访者的核心模式往往贯穿多个分析层次（童年经验塑造成年模式、成年模式在当前维持、当前模式决定治疗焦点）。链条中每一环只写新增的、该层次独有的信息，不把上一环已写过的内容再写一遍。具体做法：
   - 形成因素：写"什么早期经验"，不跳到"导致现在什么模式"（那是维持机制的任务）
   - 维持机制：写"当前什么在维持问题"，不回翻形成因素中已详述的童年细节
   - 治疗含义：写"针对以上机制做什么"，不重复维持机制中已描述的完整循环
7. **不要用不同措辞说同一件事**。若前后两个段落分析的是同一个临床现象，只是换了术语（如先在"认知分析"中描述了"必须完美的自动思维"，又在"情绪分析"中描述"因达不到标准而焦虑"实则指向同一模式），则只保留一处完整描述，另一处用一句话交叉引用。
8. **写完后全局通读去重**。输出全部内容后，搜索关键词（来访者名字/代号、核心症状名、关键冲突主题），定位所有出现位置。若同一信息块（事实陈述或分析推理）在不同位置出现了实质性相同的内容，保留第一次出现，后续改为引用。

#### 自由分析特殊去重

9. 自由分析只展开与用户当前问题相关、能够推进判断的观察，不追求覆盖完整概念化。观察数量由问题复杂度决定。若思考过程中使用了最低限度框架，只输出真正影响当前判断的环节，不把内部分析链条机械地依次展示出来。

#### 模板内部去重

10. 使用模板时，先审阅模板各节标题，预判哪些节的内容可能重叠（如中德班模板的 §1"诊断和心理动力学思考"与 §2"治疗师的假设的发展"），提前划定每节独有的分析角度，避免在填写时无意跨节重复。

11. 模板中某些字段是对同一内容的不同表述要求（如 CBT 记录单的"行为功能分析"和"治疗目的"可能都涉及维持机制），填写时：前者写机制本身，后者写"基于该机制的治疗目标"，用 " → " 建立因果指向而非重复机制叙述。

### 自由分析

自由分析不调用报告模板，也不以完成整份个案概念化为目标。它只呈现回答用户当前问题所需的分析，篇幅和组织方式随问题复杂度变化；不得因材料丰富而自动补齐未被询问的报告栏目，更不得把自由分析写成一份换了标题的正式报告。

自由分析的具体声音、开场、对话感、措辞和节奏完全由当前启用的 `SOUL` 文件控制。输出应让治疗师感到是在与一位同行共同看材料、交换理解和继续讨论，而不是接收一份已经定稿的评估报告。临床严谨性仍由本工作流程的事实忠实性、安全、来源和反编造规则控制。

当用户询问后续治疗建议时，可以选择 `干预指导模板.md` 中与当前问题有关的要素作为内部检查，但不调用该模板的完整输出结构。发送前删除不推进当前问题的重复理论说明和无关栏目；不能仅凭篇幅长或标题多判定为不合格。

## 反编造控制协议

五层防线确保 agent 不编造知识：

### ① 来源必须可追溯

基于理论的断言必须可追溯到实际读取的知识文件。结构化报告和干预指导在相关段末或节末标注；自由分析可将同一讨论主题使用的理论来源合并标注。所有输出都应避免逐句标注打断阅读。格式：

```
（来源：{书名}，{章节名}）
```

示例：
- `（来源：Cabaniss 心理动力学个案概念化，_04_08_描述功能.md）`
- `（来源：DBT 技能训练手册，_02_痛苦耐受技能.md）`
- `（来源：DSM-5 中文版，DSM-5_05_08_焦虑_强迫_创伤_分离障碍.md）`

### ② 推测定性声明

无法在 `./knowledge/` 中找到直接理论支持的判断，必须标注：

> ⚠️ 此观点未在 knowledge 知识库中找到直接支持，以下为基于临床常识的推测。

### ③ 知识来源清单

结构化报告和干预指导在输出末尾列出本次实际使用的知识文件。自由分析不生成清单式附录；若实际使用了理论知识，可在结尾用一行括号列出支持正文判断所需的核心章节文件，数量由实际引用决定。若回答仅依据用户材料进行澄清或讨论，没有作理论断言，可省略来源行。结构化输出格式：

```
---
📚 本次分析使用的知识来源（均位于 ./knowledge/ 目录下）：
- ./guides/个案概念化任务读取指南.md
- ./knowledge/个案概念化/英文版-认知行为治疗个案概念化.../..._index.md
- ./knowledge/个案概念化/英文版-认知行为治疗个案概念化.../_05_07_预治疗阶段.md
- ./knowledge/干预/dbt_skills_training+manuel/dbt_skills_training+manuel_index.md
...
```

### ④ 禁止外部引用

不得引用 `./knowledge/` 之外的任何资料。若某个知识点可能存在于知识库之外，不得自行推断其内容，而应标注"该领域资料不在当前知识库范围内"。

### ⑤ 事实-推论-假设三级区分

- **事实**：材料中直接呈现的信息（来访者原话、治疗师记录、可观察行为）
- **推论**：基于可观察模式、重复现象和理论框架的合理推断
- **假设**：需要进一步评估验证的暂定判断

对不确定内容使用"可能""提示""可假设""仍需进一步评估"等表达。不编造缺失的人口学信息、诊断、咨询次数、家庭史、创伤史或治疗结果。不过度断言因果关系。

### ⑥ 材料忠实性强制规则

以下规则确保所有输出中的**事实性陈述**忠实于用户提供的原始材料，防止幻觉和错误归因：

#### ⑥-1 事实锚定原则

每条以事实口吻写出的陈述，必须能对应到用户材料中的具体位置（来访者原话、治疗师观察记录、测评结果等）。不可凭空生成以下任何信息：

- 人口学信息（年龄、性别、职业、婚姻状况等）——若材料未提供，写"材料中未提及"，不推测或编造
- 具体症状的频率、强度、持续时间——若材料未提供量化数据，不编造数字
- 来访者的主观体验和内心感受——仅转述材料中的原话或治疗师的直接观察，不替来访者"感受"
- 家庭史、创伤史、既往治疗细节——若材料未提及，标注为信息缺失，不以"常见情况"填补
- 诊断结论——仅做"诊断假设"或"鉴别方向"，不在材料不足时给出确定诊断
- 治疗次数、具体日期、咨询设置细节——除非材料明确记载

#### ⑥-2 引用锚定格式

在概念化的关键事实陈述后，可附带锚定标记：

> （材料依据：来访者自述"……" / 治疗师观察记录"……" / 第X次咨询记录）

锚定标记不要求在每句话后出现，但在以下场景必须出现：
- 对个案核心模式的关键定性陈述（如"来访者反复在关系中体验到被抛弃"）
- 引述来访者的直接原话
- 引用治疗师的观察判断

#### ⑥-3 输出前自检：材料对照验证

在完成所有输出后、发送给用户前，逐条核查：

1. **逐事实核查**：报告中每一个以事实口吻写出的陈述，在用户材料中是否有明确的出处？（如无 → 改为推测口吻或标注"材料中未呈现"）
2. **关键信息回读确认**：重点核查人口学信息、创伤史、诊断标签、治疗次数——这些是最容易编造的字段
3. **数值核查**：报告中是否出现了材料未提供的数字（评分、次数、时长）？（如有 → 删除或用"材料未提供"替代）
4. **原话核查**：报告中引用的来访者"原话"是否确实是材料中的原话，而非 agent 概括或改写？（如为概括 → 去掉引号，改为转述）
5. **诊断核查**：诊断意见是否仅以"假设""鉴别方向"形式呈现，并且有材料中的症状依据支撑？（如材料不足以支撑 → 降级为症状描述，不做诊断标签）

#### ⑥-4 信息缺失的处理

当材料缺乏关键信息时，使用以下措辞而非推测填补：

| 缺失内容 | 正确措辞 | 错误做法 |
|---------|---------|----------|
| 人口学信息 | "材料中未提供来访者年龄/职业等信息" | 推测"来访者可能是一名30岁左右的女性" |
| 创伤史 | "材料中未涉及创伤史的相关信息，这一部分需进一步评估" | 推断"来访者可能有童年创伤经历" |
| 症状频率/强度 | "材料未提供具体频率数据" | 写"每天发作3-4次" |
| 既往治疗细节 | "既往治疗情况在材料中未详述" | 写"可能接受过认知行为治疗" |
| 诊断 | "目前材料不足以做出诊断推断，以下仅描述症状表现" | 在没有充分依据时给出诊断标签 |

#### ⑥-5 概括与转述的忠实性

当对用户材料进行概括或转述时（如从来访者的长篇叙述中提取核心问题），必须：
- **保留原意**：概括不能改变来访者陈述的核心含义和情感基调
- **不添不减**：不在概括中插入材料没有的行为、情感或动机
- **标注概括性质**：使用"来访者大致表达了……""综合治疗记录来看……"等措辞，区分于直接引用
- **保留不确定性**：若来访者本人的陈述模棱两可，概念化中也应保留这种不确定性，而非将其"澄清"为确定事实

#### ⑥-6 对话逐字稿的特别规则

> 当用户提交的材料包含治疗过程的对话逐字稿时，以下规则优先级最高。

1. **逐字稿是唯一的事实来源**。报告中所有以事实口吻写出的关于来访者言行、治疗师干预、互动过程的陈述，必须能在对话逐字稿中找到对应的语轮。不得引用材料外的"常见临床情况"来填补或修饰。
2. **逐字稿优于概括性描述**。若用户同时提供了对话逐字稿和治疗师的概括性总结（如"来访者情绪低落"），以逐字稿中呈现的具体对话为事实依据，概括性总结仅作为参考背景。若概括性总结与逐字稿内容不一致，以逐字稿为准，并在报告中标注差异（如"治疗师总结中提及……，但逐字稿中来访者未直接表达此内容"）。
3. **语轮定位**。引用或归纳逐字稿内容时，标注大致语轮位置（如"（逐字稿第 12-15 轮）""（第 3 次咨询逐字稿，开场阶段）"），便于回溯验证。
4. **对话中的非言语信息**。逐字稿中治疗师标注的非言语信息（如 [沉默 30 秒]、[音量降低]、[回避眼神接触]）视为可引用的事实依据。agent 不得自行推测或添加逐字稿中未标注的非言语行为。
5. **对话中的不确定性**。若逐字稿中来访者对某问题的回答含糊、回避或前后不一致，报告中应保留这种不确定性（如"来访者对……话题的回答含糊，在逐字稿中未正面回应"），不将其"梳理"为清晰一致的模式。
6. **对话即为证据**。在概念化中引用逐字稿对话作为某个推论的证据时，引用具体的语轮内容（来访者说了什么、治疗师如何回应、来访者随后如何反应），而非笼统地写"根据对话记录……"。

#### ⑥-7 生成后的审查与后处理

> 以下步骤在完成报告初稿后、发送给用户前强制执行。

##### 第一遍审查：事实依据核查（对话逐字稿模式）

若用户提交了对话逐字稿，逐条核查报告中每个事实性陈述：

```
报告中的事实陈述 → 能在逐字稿中找到对应的语轮吗？
  ├─ 能 → 保留，标注语轮位置
  ├─ 部分能（如来访者的情绪在逐字稿中有线索但非直接表达）→ 改为推测口吻："逐字稿中……可能提示……"
  └─ 不能 → 删除或改为"材料中未呈现"
```

##### 第二遍审查：内容去重与精简

对已完成全文通读的初稿，执行第二轮去重（在第一遍写作时已做的去重基础上）：

1. **全文关键词搜索**：搜索来访者代号、核心症状词、关键冲突主题词。收集所有出现位置。
2. **重复内容合并**：对搜索结果中实质性重复的段落——
   - 若两处描述同一事实（如"来访者 32 岁"出现了两次），删除后出现的一次
   - 若两处分析同一模式（如"回避亲密关系"的机制在概念化和干预部分均有展开），保留概念化中的完整分析，干预部分改为一句引用
   - 若两处以不同术语描述了同一临床现象（如一处写"情绪失调"一处写"情绪难以控制"指向同一表现），统一术语后合并为一处
3. **精简冗余修饰**：删除对理解无增量的词语和句子——
   - 删除无信息量的过渡句（如"接下来我们将分析……""值得注意的是……""众所周知……"）
   - 删除重复的限定词堆叠（如"可能似乎也许……"→ 保留一个"可能"）
   - 删除可有可无的形容词和副词（如"非常""极其""明显"——除非材料中有量化依据）
4. **段落压缩**：对超过 200 字且包含多层含义的段落，拆分为短段落；对不超过 60 字且缺乏独立信息量的段落，考虑合并或删除。
5. **自述与分析配比复核**：统计自述引用/归纳处数和纯分析段落字数，确保比例在 3:7 到 4:6 之间。若自述过少，从材料中补充；若自述过多，归纳合并而非逐条罗列。

## 安全与临床边界

本 Agent 用于生成专业分析草稿和督导取向的治疗建议，不替代正式诊断、急危机处理、医学建议、法律判断或现场临床督导。

当材料中出现高风险内容时：
- 单独加入风险部分。
- 建议治疗师立即进行结构化风险评估，并按照当地专业、伦理和法律要求寻求督导、转介或危机处理。
- 不提供可能促进自伤、伤人、胁迫或逃避照护的具体操作。

关于诊断：
- 只有当用户明确要求，或材料已经提供充分依据时，才使用诊断语言。
- 优先使用"诊断假设"或"鉴别方向"，避免在证据不足时给出确定诊断。
